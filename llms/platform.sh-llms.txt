# Platform.sh (now Upsun)

> Platform.sh is a container-based Platform-as-a-Service: a single `git push` plus a few YAML files
> provisions an entire cluster of applications and managed services, with byte-for-byte preview
> environments cloned from production. The company rebranded to Upsun — platform.sh redirects to
> upsun.com, the original Platform.sh product is documented as "Upsun Fixed", and the public REST API
> still authenticates against auth.api.platform.sh.

## Authentication

- OAuth 2.0 bearer. Authorization server: https://auth.api.platform.sh
  - authorization_code with PKCE (S256), and client_credentials with the `admin` scope
  - API tokens are exchanged for a 900-second bearer token:
    POST https://auth.upsun.com/oauth2/token with grant_type=api_token
  - Discovery: /.well-known/openid-configuration, /.well-known/oauth-authorization-server,
    /.well-known/oauth-protected-resource (all 200 on auth.api.platform.sh)
- Artifacts: authentication/platform.sh-authentication.yml, scopes/platform.sh-scopes.yml

## Runtime semantics an agent needs

- Errors: RFC 9457 `application/problem+json` — errors/platform.sh-problem-types.yml
- Pagination: cursor — `page[after]`, `page[before]`, `page[size]`, plus `sort` and `filter[...]`
- Hypermedia: HAL `_links` with `self`, `#edit`, `#delete` entries carrying OpenAPI schema in `meta`
- Idempotency: NOT supported. No Idempotency-Key header on any of the 115 write operations.
- Rate limits: none published. No 429 responses and no RateLimit-* headers in the contract.
- Long-running work: returns an Activity; poll it rather than holding the connection.
- Reversibility: restore-backup reverses environment data loss. Automated backups are retained 2 days
  under the default policy; manual backups until deleted. Environment and project DELETE have no
  undelete operation.
- Conventions artifact: conventions/platform.sh-conventions.yml
